# Decisiones del proyecto

Las decisiones aquí son **parte de la constitución** una vez ratificadas. Formato ADR (Architecture Decision Record).

## Cómo añadir una decisión

1. Copiar `_template.md` al siguiente número: `NNNN-titulo-kebab.md`.
2. Completar Contexto, Decisión, Consecuencias y artículo constitucional afectado.
3. Enlazarla en `docs/constitution.md` §6.
4. Si cambia un principio, subir la versión de la constitución.
